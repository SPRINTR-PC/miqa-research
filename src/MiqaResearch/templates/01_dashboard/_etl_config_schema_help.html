{% translate "Config schema" %}

{% translate "Optional. It describes the settings your script accepts, such as a CSV delimiter, file encoding or column names. Those settings belong to the Pipeline Binding, not to the script; the script reads them at run time as ctx.config." %}

{% translate "Without a schema, a Binding's config is free-form JSON and nothing is checked until the script fails. With one, the Binding forms show one field per top-level property, using its title as the label and its description as the help text, and a config that does not fit is rejected when the Binding is created, edited or re-pinned to this version. Each script version can carry its own schema." %}

{% translate "Write a JSON Schema (Draft 2020-12) whose top level is an object, or load it from a .json file. For example:" %}

{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "delimiter": {
      "type": "string", "minLength": 1, "maxLength": 1,
      "title": "Delimiter",
      "description": "CSV field delimiter. Default: \",\"."
    },
    "encoding": {
      "type": "string",
      "title": "Encoding",
      "description": "File encoding."
    }
  },
  "required": [],
  "additionalProperties": false
}
  • properties: {% translate "the settings; each title and description becomes the form label and help text." %}
  • required: {% translate "keys that must be set." %}
  • additionalProperties: false: {% translate "rejects keys the schema does not list, which catches typos." %}

{% translate "If your script has no per-source settings, leave this empty. You can add a schema later by saving a new version." %}
